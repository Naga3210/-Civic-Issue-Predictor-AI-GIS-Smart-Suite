# 🏙️ CivicIssue Predictor — AI & GIS Smart Suite

An AI-driven civic issue classification, prediction, and routing platform built using **Streamlit**, **Machine Learning (Scikit-Learn)**, and **Interactive GIS Analytics**.

---

## ✨ Features

- **📍 Smart Complaint Registration**: Multi-modal reporting supporting custom location mapping, image upload analysis mockups, and voice note audio logs.
- **🤖 ML Priority Prediction**: Auto-classifies civic issues into **HIGH**, **MEDIUM**, or **LOW** priority using a Random Forest Classifier trained on severity and historical patterns.
- **🗺️ Live GIS Mapping**: Interactive geographic spatial view displaying reported complaints across city zones.
- **🚚 Route Optimization**: Priority-based sorting to help municipal maintenance crews tackle high-severity issues first.
- **📊 City Administration Analytics**: Interactive pie charts and bar plots powered by Plotly to track SDG 11 compliance and issue trends.

---

## 🛠️ Tech Stack

- **Frontend / Dashboard**: [Streamlit](https://streamlit.io/)
- **Machine Learning**: `scikit-learn` (RandomForestClassifier)
- **Data Processing**: `pandas`, `numpy`
- **Visualization**: `plotly`, `streamlit.map`
